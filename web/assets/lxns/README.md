# LXNS score badge assets

The WebP files in this directory were downloaded from the badge paths used by
`https://maimai.lxns.net/` on 2026-07-15 so the local application can render
the same achievement and completion badges without hotlinking.

Source path patterns:

- `https://maimai.lxns.net/assets/maimai/music_rank/*.webp`
- `https://maimai.lxns.net/assets/maimai/music_icon/*.webp`
- `https://maimai.lxns.net/assets/chunithm/music_rank/*.webp`
- `https://maimai.lxns.net/assets/chunithm/music_icon/*.webp`

Keep the original file names because the frontend maps score/status values to
these names directly.
