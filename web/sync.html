    步骤 1

    启动 Helper 并配置代理

    需要手动配置

    先在项目根目录运行 .\run-wechat-helper.ps1 并保持终端开启。推荐沿用原抓取方式，让微信通过标准 HTTP 代理直接连接 Helper；Clash 作为备选，两种方式只启用一种。

    请手动填写 127.0.0.1，或运行 Helper 的电脑私网 IPv4；页面不会自动探测或回填。

    出现 504 通常表示回调没有进入 Helper：请确认 Clash 中已激活刚导入的 Helper 配置（卡片呈选中状态），或关闭 Clash、Fiddler、Charles 后改用标准 HTTP 代理。仅“导入”配置不会自动激活。

    Clash 配置

    点击按钮只会唤起 Clash 并导入配置，Clash 不允许网页替你切换运行配置。导入后请在订阅页点选新出现的 Helper 配置，确认卡片处于选中状态；若手动合并 YAML，规则必须放在现有 MATCH 等终止规则之前。同步期间不要同时运行 Fiddler、Charles 或另一套系统代理。

    导入 Clash 配置
    标准 HTTP 代理（推荐，与原抓取方式一致）

    先关闭 Clash、Fiddler、Charles 及其他系统代理，再在 Wi-Fi 或移动网络的代理设置中选择“手动”或“HTTP 代理”，服务器填写上方 Helper 地址，端口填写 8081。抓取结束后请关闭该代理。
